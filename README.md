# Tetris

Консольная игра "Тетрис" на C#

## Возможности

* Падающие фигуры
* Вращение фигур
* Движение фигур
* Игровое поле
* Конец игры
* Перезапуск игры

## Управление

* ← движение влево
* → движение вправо
* ↑ поворот
* ↓ ускорение

* C#
* Console Application
